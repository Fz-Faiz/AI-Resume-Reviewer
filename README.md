# 📄 AI Resume Reviewer

An **AI-powered Resume Reviewer** that helps users analyze and improve their resumes using modern AI techniques.

Built with **MERN Stack + LangChain**, designed for scalability and real-world usage.

## 🔄 How It Works

- User signs up / logs in

- Uploads resume (PDF)

- Backend sends resume to AI service

- LangChain analyzes resume

- Feedback & suggestions are returned

- User edits and improves resume
